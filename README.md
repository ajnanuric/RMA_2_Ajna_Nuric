# TripBuddy 

TripBuddy je Android mobilna aplikacija za planiranje putovanja razvijena u Java programskom jeziku koristeći Android Studio razvojno okruženje.

Aplikacija omogućava korisnicima organizaciju putovanja, pregled destinacija, planiranje budžeta, spremanje bilješki i upravljanje važnim informacijama vezanim za putovanja kroz moderan i jednostavan korisnički interfejs.

---

## Funkcionalnosti aplikacije

- Login i registracija korisnika
- Firebase autentifikacija
- Home screen sa travel destinacijama
- Trips screen
- Trip Planner screen
- Budget planner
- Packing lista
- Flights organizacija
- Hotels pregled
- Notes sekcija
- Documents sekcija
- Shop screen
- Profile screen
- Dark mode opcija
- Bottom navigation meni

##  Struktura projekta

Projekt je organizovan kroz više paketa radi preglednosti i lakšeg održavanja aplikacije.

### Glavni paketi:

- `activities` – aktivnosti aplikacije
- `fragments` – fragmenti za navigaciju između ekrana
- `adapters` – adapteri za prikaz podataka
- `database` – Room baza podataka i DAO klase
- `firebase` – Firebase autentifikacija
- `layout` – XML fajlovi za dizajn korisničkog interfejsa
